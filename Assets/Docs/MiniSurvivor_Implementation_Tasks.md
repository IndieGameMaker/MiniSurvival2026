# MiniSurvivor 구현 Task 계획

## 목표

2일 동안 초보자가 완성할 수 있는 2D 탑다운 서바이벌 프로토타입을 만든다.

- 플레이어는 WASD 또는 방향키로 이동한다.
- 플레이어는 일정 간격으로 가장 가까운 적에게 자동 발사한다.
- 적은 화면 가장자리 밖에서 생성되어 플레이어를 추적한다.
- 투사체에 맞은 적은 사라지고 경험치 젬을 떨어뜨린다.
- 젬을 획득하면 점수가 증가한다.
- 적과 접촉하면 HP가 감소하고, HP가 0이 되면 게임오버된다.
- 60초 동안 생존하면 클리어된다.

각 Task는 프롬프트 한 번으로 요청할 수 있는 크기로 나눈다.

## 1일 차: 이동, 적, 전투

### Task 1. 메인 게임 Scene 준비

> `Assets/Scenes/MainGame.unity` 씬을 만들고 Main Camera와 Global Light 2D를 배치해줘. Build Settings의 시작 씬으로 등록하고 다른 게임 기능은 만들지 마.

완료 기준: 빈 2D 씬이 실행되고 카메라가 정상적으로 보인다.

### Task 2. 플레이어 Prefab 준비

> 간단한 임시 Sprite로 Player GameObject를 만들고 SpriteRenderer, Rigidbody2D, Collider2D를 설정한 뒤 `Assets/Prefabs/Player.prefab`으로 저장해줘. 이동 코드는 아직 만들지 마.

완료 기준: Player가 씬 중앙에 보이며 중력으로 떨어지지 않는다.

### Task 3. 이동 입력 설정

> Input System에 WASD와 방향키를 사용하는 `Move` 액션을 추가해줘. 플레이어 이동 코드는 아직 작성하지 마.

완료 기준: Input Actions 창에서 2D Vector 이동 입력을 확인할 수 있다.

### Task 4. 플레이어 이동 구현

> `PlayerMovement` 스크립트를 만들어 Input System의 Move 입력으로 Player가 상하좌우 이동하게 해줘. 이동 속도는 Inspector에서 조절할 수 있게 해줘.

완료 기준: WASD와 방향키로 부드럽게 이동한다.

### Task 5. 플레이어 화면 이탈 방지

> PlayerMovement에 플레이어가 Main Camera 화면 밖으로 나가지 않도록 위치를 제한하는 기능을 추가해줘.

완료 기준: 어느 방향으로 계속 이동해도 플레이어 전체가 화면 안에 남는다.

### Task 6. 적 Prefab 준비

> 임시 Sprite로 Slime GameObject를 만들고 SpriteRenderer, Rigidbody2D, Collider2D를 설정한 뒤 `Assets/Prefabs/Slime.prefab`으로 저장해줘. 추적 코드는 아직 만들지 마.

완료 기준: Slime Prefab을 씬에 배치하면 정상적으로 보인다.

### Task 7. 적 추적 이동 구현

> `EnemyMovement` 스크립트를 만들어 Slime이 Player를 향해 직선으로 이동하게 해줘. 이동 속도는 Inspector에서 조절할 수 있게 해줘.

완료 기준: Slime을 씬에 놓으면 플레이어를 계속 따라온다.

### Task 8. 화면 가장자리 적 스폰 구현

> `EnemySpawner`를 만들어 Slime이 카메라 화면 바깥쪽의 임의 위치에서 2초마다 생성되게 해줘. 생성 간격과 화면 밖 여백은 Inspector에서 조절할 수 있게 해줘.

완료 기준: 적이 화면 내부에서 갑자기 나타나지 않고 네 방향 가장자리 밖에서 등장한다.

### Task 9. 투사체 Prefab 준비

> 임시 Sprite로 Projectile을 만들고 필요한 2D Collider를 설정한 뒤 `Assets/Prefabs/Projectile.prefab`으로 저장해줘. 발사와 충돌 코드는 아직 만들지 마.

완료 기준: Projectile Prefab을 수동 배치하면 정상적으로 보인다.

### Task 10. 투사체 이동 구현

> `Projectile` 스크립트를 만들어 지정된 방향으로 일정한 속도로 이동하고 3초 후 자동으로 사라지게 해줘. 속도와 유지 시간은 Inspector에서 조절할 수 있게 해줘.

완료 기준: 생성된 투사체가 직선 이동하고 3초 후 제거된다.

### Task 11. 가장 가까운 적 자동 공격

> `PlayerAutoAttack` 스크립트를 만들어 현재 살아 있는 적 중 가장 가까운 적을 찾아 0.8초마다 Projectile을 발사하게 해줘. 발사 간격과 Projectile Prefab은 Inspector에서 설정하게 해줘.

완료 기준: 적이 있을 때만 가장 가까운 적을 향해 자동 발사한다.

### Task 12. 적 체력과 사망 처리

> `EnemyHealth` 스크립트를 만들어 Slime의 HP를 1로 설정하고 피해를 받으면 사망하게 해줘. HP는 Inspector에서 조절할 수 있게 하고 젬 드롭은 아직 구현하지 마.

완료 기준: 테스트용 피해를 주면 Slime이 한 번에 제거된다.

### Task 13. 투사체 명중 처리

> Projectile이 Enemy와 충돌하면 EnemyHealth에 피해 1을 주고 Projectile도 즉시 사라지게 연결해줘.

완료 기준: 투사체 한 발에 Slime과 투사체가 모두 제거된다.

## 2일 차: 젬, 성장, HP, 게임 진행

### Task 14. 경험치 젬 드롭

> 임시 Sprite로 ExperienceGem Prefab을 만들고 Slime이 사망한 위치에 젬 하나를 생성하게 해줘. 획득과 점수 기능은 아직 만들지 마.

완료 기준: 투사체로 적을 처치하면 그 자리에 젬이 남는다.

### Task 15. 젬 획득과 점수

> `ScoreManager`와 젬 획득 기능을 만들어 Player가 ExperienceGem에 닿으면 젬이 사라지고 점수가 10 증가하게 해줘.

완료 기준: 젬을 먹을 때마다 내부 점수가 10씩 증가한다.

### Task 16. 레벨업과 공격 속도 증가

> 획득한 젬 5개마다 레벨이 1 오르게 하고, 레벨업할 때 PlayerAutoAttack의 발사 간격을 10% 줄여줘. 최소 발사 간격은 0.2초로 제한해줘.

완료 기준: 젬 5개를 먹으면 레벨이 오르고 자동 공격이 빨라진다.

### Task 17. 플레이어 HP와 접촉 피해

> `PlayerHealth`를 만들어 최대 HP를 5로 설정하고 Slime과 접촉하면 HP가 1 감소하게 해줘. 한 번 접촉한 Slime은 제거해서 피해가 연속으로 적용되지 않게 해줘.

완료 기준: 적 한 마리와 접촉할 때 HP가 정확히 1 감소한다.

### Task 18. HUD 제작

> TextMeshPro를 사용해 왼쪽 위에 HP, 가운데 위에 점수와 레벨, 오른쪽 위에 남은 시간을 표시하는 HUD를 만들어줘. 기존 시스템의 값과 연결해줘.

완료 기준: 플레이 중 HP, 점수, 레벨, 시간이 실시간으로 갱신된다.

### Task 19. 60초 타이머와 게임 종료

> `GameManager`를 만들어 게임 시작 후 60초를 계산하고, Player HP가 0이면 게임오버, 60초를 생존하면 클리어 처리해줘. 종료되면 적 생성과 플레이어 조작을 멈춰줘.

완료 기준: 사망과 60초 생존이 서로 다른 결과로 처리된다.

### Task 20. 시작·결과 화면과 재시작

> 타이틀 화면, 게임오버 화면, 클리어 화면을 만들어줘. Space를 누르면 게임이 시작되고 결과 화면에서 R을 누르면 게임을 재시작하게 해줘.

완료 기준: 타이틀 → 플레이 → 결과 → 재시작 흐름이 완성된다.

### Task 21. 시간에 따른 난이도 증가

> EnemySpawner의 생성 간격이 생존 시간 30초마다 10% 감소하게 해줘. 최소 생성 간격은 0.5초로 제한해줘.

완료 기준: 30초 이후 적 생성이 빨라지며 설정한 최소값 아래로 내려가지 않는다.

### Task 22. 전체 통합 점검

> MainGame 씬의 전체 게임 흐름을 점검해줘. 플레이어 이동, 적 생성과 추적, 자동 공격, 젬 획득, 레벨업, 접촉 피해, 게임오버, 60초 클리어, 재시작 순서로 테스트하고 발견한 오류만 수정해줘.

완료 기준: 처음부터 결과 화면과 재시작까지 전체 흐름이 끊기지 않고 동작한다.

## 구현 순서의 기준

먼저 `이동 → 적 추적 → 자동 공격 → 처치`로 이어지는 핵심 플레이를 완성한다. 이후 젬, 점수, 레벨, HP, 타이머와 화면 UI를 차례로 연결한다. 각 Task를 마칠 때 완료 기준만 확인한 후 다음 Task로 넘어간다.
